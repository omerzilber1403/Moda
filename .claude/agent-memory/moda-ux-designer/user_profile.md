Working on FitFlip — a Tinder-style Flutter app for swapping second-hand clothes. The project is production-quality focused with an emphasis on premium visual design.

Wants all UI to feel Bumble/Tinder 2024-quality: glassmorphism everywhere, smooth animations, image-first design, generous whitespace. Explicitly does NOT want flat or opaque UI.

Engages at a senior engineering level — provides detailed, structured design specs with numbered items and specific widget-level requirements. Comfortable with Flutter internals (BackdropFilter, animation controllers, Riverpod).

When given a redesign task, expects every widget and screen listed to be addressed — not just the ones that need the most work.
